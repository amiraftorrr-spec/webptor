# webptor — Modern Image to WebP Converter ⚡

A high-performance, private, client-side WebP image converter built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. Optimized for seamless one-click deployment on **Vercel**.

## 🚀 Key Features

- 🔒 **100% In-Browser Conversion**: Images are processed directly in your browser via HTML5 Canvas and Web APIs. Zero data is uploaded to remote servers.
- ⚡ **Universal Format Support**: Converts PNG, JPG, JPEG, GIF, SVG, BMP, AVIF, HEIC/HEIF, TIFF, ICO, and any image format to WebP.
- 🎚️ **Simple Quality Presets**: Quick switch between Max Compress (60%), Balanced (80%), High Quality (92%), and Lossless (100%).
- 📦 **One-Click ZIP Export**: Download all converted WebP files in a single organized ZIP archive.
- 🔍 **Interactive Before/After Comparison**: Compare original image quality vs WebP side-by-side using an interactive slider.
- 🌗 **Dark & Light Mode**: Sleek modern UI with dark mode enabled by default and smooth theme toggling.
- ☁️ **Vercel Ready**: No backend dependencies or server payload limits — 100% serverless and static-friendly.

## 💻 Getting Started Locally

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 3. Build for production
```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel

The easiest way to deploy this project is via the [Vercel Platform](https://vercel.com/new):

1. Push your repository to GitHub or GitLab.
2. Import your repository into **Vercel**.
3. Keep default settings (`Framework Preset: Next.js`).
4. Click **Deploy**!
